# 参考资源

> 按来源组织，供学习过程中查阅。

## 官方文档

- [Microsoft 官方 C# 函数式编程指南](https://learn.microsoft.com/zh-cn/dotnet/csharp/functional/)
  - 微软官方对 C# 中函数式特性的说明，包括模式匹配、不可变性、纯函数等
- [C# 语言规范 - Lambda 表达式](https://learn.microsoft.com/zh-cn/dotnet/csharp/language-reference/operators/lambda-expressions)
- [C# 委托 (Delegate) 文档](https://learn.microsoft.com/zh-cn/dotnet/csharp/programming-guide/delegates/)
- [LINQ (Language Integrated Query) 文档](https://learn.microsoft.com/zh-cn/dotnet/csharp/linq/)

## 书籍

- **《Functional Programming in C#》** — Enrico Buonanno
  - 系统讲解如何在 C# 中实践函数式编程，从基础到高级模式
- **《Functional C#》** — Wisnu Anggoro
  - 偏实战，包含大量可运行的代码示例
- **《Real-World Functional Programming: With Examples in F# and C#》** — Tomas Petricek
  - 同时用 F# 和 C# 对比讲解，适合想深入理解函数式思维的人

## 社区文章与教程

- [Functional Programming in C# — 系列教程 by Vladimir Khorikov](https://enterprisecraftsmanship.com/posts/functional-csharp-principles/)
  - 深入浅出，包含很多 C# 函数式实践中的坑
- [C# Functional Programming Examples (GitHub)](https://github.com/la-yumba/functional-csharp-code)
  - 《Functional Programming in C#》的配套代码仓库
- [Discriminated Unions in C#](https://blog.nullspace.io/discriminated-unions-csharp.html)
  - 探讨如何在 C# 中模拟联合类型（Sum Types）

## 视频资源

- [C# Functional Programming with Lambda Expressions (Nick Chapsas)](https://www.youtube.com/watch?v=7jxMFj0J_9g)
  - 约 25 分钟，适合快速了解
- [Functional Programming in C# — Stefan Dokic (YouTube)](https://www.youtube.com/watch?v=Kp1PjNxLk0Q)
  - 约 40 分钟，涵盖核心概念

## 开源库

- [Language-Ext](https://github.com/louthy/language-ext)
  - C# 中最完善函数式编程库，提供 Option、Either、Reader、Writer 等 Monad
- [Optional](https://github.com/nlkl/Optional)
  - 轻量级 Option 类型库，适合入门
- [Funcky](https://github.com/polyadic/funcky)
  - 函数式扩展方法集合，包含 Monad 组合子
