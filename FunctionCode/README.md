# C# 函数式编程学习计划

## 概述

这是一个系统化的学习路径，帮助你以 C# 为基础，掌握函数式编程的核心思想与实践模式。
无论你是初学者还是有一定经验的 C# 开发者，这份计划都会引导你循序渐进地理解函数式编程。

## 如何学习

1. **按顺序完成五个等级**——每个等级建立在前一个等级之上
2. **动手运行代码示例**——每个等级都配有可运行的控制台项目
3. **在学习路径文档 (learning-path.md) 中记录练习与笔记**
4. **完成 Level 5 的迷你项目**巩固所学

## 学习前提

- 熟悉 C# 基本语法（类、方法、委托）
- 安装了 .NET 8 SDK 或更高版本
- 能够使用命令行运行 `dotnet run`
